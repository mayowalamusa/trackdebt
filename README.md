# Track Debt

Track Debt helps Nigerian business owners track customer credit sales, send WhatsApp payment reminders, and manage outstanding balances — fully offline, right from their phone.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
# Web / Lovable deployment
npm run build

# Capacitor client (Android)
npm run build:capacitor
```

## Tech stack

- React + TypeScript
- TanStack Start (SSR)
- TanStack Router
- Tailwind CSS v4
- Capacitor (Android)
- Supabase (auth + cloud)
- Paystack (payments)
